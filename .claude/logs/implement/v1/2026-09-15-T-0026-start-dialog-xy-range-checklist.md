## 人手確認チェックリスト

### 確認手順
1. QGISで本プラグインを起動し、「点群座標取得」の起動時ダイアログ（セッション選択画面）を開く。
2. 「新規セッション」を選択した状態で、「グリッド設定」パネル内に、従来の「グリッド数:」1行の代わりに
   「X範囲:」「Y範囲:」の2行が表示されていることを確認する。
   - 「X範囲:」行には「最小:」「最大:」のラベル付き通常の数値スピンボックス（半角数字）が2つ表示される。
   - 「Y範囲:」行には「最小:」「最大:」のラベル付きスピンボックスが2つ表示され、
     数値ではなく `A`, `B`, …, `Z`, `AA`, `AB`, … のような半角英大文字表記で値が表示・入力できることを確認する。
3. Y範囲のスピンボックスに、上下矢印（スピナー）で値を増減させ、`A`→`B`→…→`Z`→`AA`→`AB`… と
   1〜2桁の英字表記が連続的に変化することを確認する。
4. Y範囲のスピンボックスに直接キーボードでテキスト入力を試み、以下を確認する。
   - 半角英字1〜2文字（例: `c`, `ab`）は入力・確定できる（小文字を入れても内部的に大文字扱いで動作する想定）。
   - 数字や3文字以上、記号等の入力は無効化される、または確定時に有効な値へ補正される。
5. 原点(1A-00)の `X:`/`Y:` と、X範囲/Y範囲の値をいくつか変更し、「グリッドプレビュー:」欄（`X:`（数値）/`Y:`（英字テキスト入力)）
   に妥当なグリッド番号を入力して、プレビュー表示（成功時: `{X}{Y}-00座標: X: ◯◯, Y: ◯◯`、範囲外時: `範囲外`）が
   X範囲・Y範囲（最小〜最大）に基づいて正しく切り替わることを確認する。
   - 特に、X範囲の最小値を1以外（例: 3）に設定した状態で、プレビューのXに1や2を入力すると「範囲外」表示になり、
     3以上最大値以下では座標が表示されることを確認する（Y範囲も同様に最小値をA以外、例えばCに設定して確認）。
6. 「セッションを開始」を押して新規セッションを作成し、セッションフォルダ内に生成される `PointGeo_grid.csv` を開き、
   以下を確認する。
   - 「大グリッドＸ」列が指定したX範囲（最小〜最大）の値のみを含み、それ以外の値（範囲外）が含まれていないこと。
   - 「大グリッドＹ」列が指定したY範囲（最小〜最大、英字表記）の値のみを含むこと。
   - 各大グリッドについて「小グリッド」列が `00`〜`99` の100行ずつ生成され、「Ｘ座標」「Ｙ座標」の値が
     原点(1A-00)からのオフセット計算（40m間隔・4m間隔）として妥当であること
     （特にX範囲・Y範囲の最小値を1/A以外に設定した場合でも、原点からの相対位置として正しい座標になっていること）。
7. 「既存セッション」を選択し、手順6で作成したセッションフォルダ（またはグリッドCSV）を選択し直して、
   「グリッド設定」パネルのX範囲・Y範囲・原点の各値が、選択したCSVの内容（手順6で確認した範囲・原点）と
   一致した値で再表示されることを確認する。
8. メインパネル（右ドック）でグリッド原点・範囲に関連する既存機能（例: グリッド座標を用いた遺物点作成、
   グリッド関連ダイアログでのX/Y入力補助等）が、従来通り動作することを一通り確認する
   （本タスクでは `layer_manager.py`/`main_dock_dialogs.py` 側のロジックは変更していないが、
   `PointGeo_grid.csv` のフォーマット・範囲が変わるため、間接的な影響がないか確認する）。

### 各手順で期待される挙動（設計書ベース）
- 手順2〜4: 依頼元タスク（T-0026）の「グリッド設定パネルのグリッド数を廃止し、X範囲・Y範囲を追加する。
  Y軸用カスタムスピンボックスは半角英大文字1〜2桁（A〜ZZ）をExcel列名方式で扱う」という要件に基づく。
- 手順5: `src/start_dialog.py` の `_update_grid_coordinate_preview()`（
  「# 【変更不可侵の絶対的ルール】 測量座標系（X軸=南北, Y軸=東西）を採用」というコメントで示される座標系定義）に基づき、
  X範囲・Y範囲（最小〜最大、両端含む）の範囲外判定が正しく行われるべき。
- 手順6: `src/grid_csv_mixin.py` の `generate_grid_csv()`
  （「Large grid: 40m x 40m」「Small grid: 4m x 4m (10x10 inside large grid)」「Output coordinates:
  Upper-left vertex of each small grid」というdocstring、および
  「origin は常に理論上の1A-00を表す点として据え置く」という本タスクの実装方針）に基づき、
  範囲の最小値が1/Aでなくても原点からの正しいオフセットでCSVが生成されるべき。
- 手順7: `src/start_dialog.py` の `_extract_csv_metadata()`（本タスクで小グリッド番号を用いた原点の逆算ロジックに変更）
  に基づき、範囲の最小値が1/Aでない既存CSVを読み込んでも、原点・範囲が正しく復元されるべき。

### 注意喚起
- `generate_grid_csv()` のシグネチャ変更（`range_x`/`range_y` → `range_x_min`/`range_x_max`/`range_y_min`/`range_y_max`）
  および `get_session_data()` が返す `grid_config`/トップレベルキーの命名変更は、
  リポジトリ全体の呼び出し元（`plugin.py`, `session_io_mixin.py`）を確認済みだが、
  もし本プロジェクト外・将来の拡張コードでこれらのキー名や関数シグネチャに直接依存する箇所を追加する場合は
  影響を受ける。
- `_extract_csv_metadata()` の原点逆算ロジックは、CSVの「小グリッド」列が `00`〜`99` の2桁数字表記であることを
  前提にしている。手作業で編集された非標準フォーマットのCSV（小グリッド列が空・別形式等）を読み込んだ場合、
  原点が正しく復元されない可能性があるため、既存CSV読み込み機能を使う場合は特に注意して確認すること。
- Y範囲用の `ExcelColumnSpinBox` は新規クラスであり、QGIS上でのキーボード入力・IME入力・貼り付け操作等での
  実際の挙動（特に大文字/小文字混在、全角文字の誤入力時の挙動）は静的検証の対象外のため、実機での確認が必要。
- X範囲・Y範囲の「最小 > 最大」のバリデーション（本タスクで新規追加）は、既存CSV指定時にはスキップされる
  （既存CSV使用時は範囲入力欄自体が無効化されるため）。新規セッション作成時のみ動作することを確認すること。
